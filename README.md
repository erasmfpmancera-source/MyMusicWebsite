Student Name: Eras Maurel Franquo P. Mancera
Website Category: Portfolio / Entertainment

Project Description
A personal portfolio website for my music production. It showcases my beats made in FL Studio and recorded on BandLab, along with my biography, social links, and a gallery of my studio setup.

## Main Features
- 5 major sections: Music & Profile, About Me, Gallery, Discography, and Contact.
- Smooth sliding tab navigation for a seamless user experience.
- Embedded BandLab music players for streaming my tracks.
- Instagram post embedding with scroll-triggered fade-in animations.
- Interactive Discography filter system (All, Beats I Made, Borrowed Beats, Covers).
- Local Storage "Like" buttons to save user feedback on tracks.
- Responsive design for mobile and desktop.

Technologies Used
- HTML5
- CSS3 (Custom animations, Flexbox, Grid, Responsive Media Queries)
- JavaScript (DOM Manipulation, Intersection Observer API, Local Storage)
- GitHub Pages (Deployment)
